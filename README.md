# RAWG Parser

Программа на языке Python для автоматического сбора данных о видеоиграх с использованием платформы RAWG API. Скрипт умеет искать популярные мультиплеерные стратегии, подтягивать скриншоты к ним и находить прямые ссылки на магазины для покупки.

## Как установить

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:

1. Скачайте файлы проекта в отдельную папку.

2. Откройте терминал в этой папке и установите необходимые зависимости:

```
pip install -r requirements.txt
```

## Как Запустить проекта

Запуск скрипта выполняется через стандартный терминал одной командой:

```
python main.py
```

После запуска программа выполнит запрос к RAWG, отберет лучшие книги, сохранит ссылки на их скриншоты и выведет в консоль список доступных магазинов для их приобретения.
